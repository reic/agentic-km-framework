你正在執行**數字健檢（基準稽核）**——專抓「**基準漂移**」這類錯誤：數字本身正確、與其他頁面也不矛盾，但在轉述時**換掉了分母／範圍／年份／口徑**（最典型：把「某公司內部占比」講成「占全球」）。這是 wiki Phase 4『掃描不一致』抓不到的盲區。動手前先讀 `wiki/WIKI.md` Phase 2「數字必帶基準」與 Phase 4「基準稽核」。

**稽核範圍**：`$ARGUMENTS`
- 指定頁面／資料夾／專案 slug → 只掃該範圍。
- 留空 → 預設掃 `wiki/derived/` ＋ `wiki/articles/`（轉述最多、最易漂移之處）。

依序做：

1. **撈出所有數字宣稱**：在範圍內 grep 出含下列特徵的行——`%`、`倍`、`億`、`兆`、`萬片`、`CAGR`、`nm`／`奈米`＋數字、年份占比、市占／份額。連同它的 `(來源: …)` 標注一起列出。沒帶出處的數字**另列一區**（缺出處本身就是缺陷）。

2. **逐條回查基準**：對每個數字，打開它引用的來源頁（summaries／raw 對應摘要），比對四件事是否與原文一致：
   - **分母**：占誰的比例？（分子/分母是否被換）
   - **範圍**：單一公司／全產業／全球？（最常見漂移點）
   - **年份**：哪一年？實際 vs 預估有沒有混用？
   - **口徑**：片/月、營收、出貨量、產能——單位有沒有被換。

3. **判級回報**（lint：先報告、不逕改）：
   - 🔴 **基準漂移**：數字對但分母／範圍／年份／口徑與來源不符 → 給「現況措辭 → 建議措辭（補回限定詞）→ 來源原文」。
   - 🟡 **基準不明**：數字沒寫清楚分母／範圍，讀者可能誤解 → 建議補上限定詞。
   - ⚪ **缺出處**：數字未附 `(來源: …)` → 建議補源或標為待查。
   - ✅ 一致：略過不列（只給總數）。

4. **修正**：把 🔴🟡⚪ 清單交使用者確認後再改（依共用慣例「大改動先取得同意」）；改完更新各頁 `updated`，並把這次稽核**事件**記進 [[wiki-log]]（若稽核對象是專案報告則記該專案 status）。**index 不堆稽核流水帳**。

**界線**：本命令只做「**揪基準漂移＋提修正案**」，不自行改寫數據、不上網補新數字（補缺漏是 Phase 4 另一動作）。**數字的最終基準以 raw 原文為準，存疑就標待查、不臆測。**
