# 趨勢 Wiki — 使用說明

把零散 clip 的新聞，變成可查詢的時間軸＋盤點＋跨主題視角，幾乎零成本累積。完整規範見 [TREND-WIKI.md](TREND-WIKI.md)。

## 日常動作
1. **匯入新聞** — clip 新聞放進 `trend-raw/YYYY/` → 說「**匯入趨勢**」（先 import_diff 比對並建完成清單、只抽新檔，每篇一行進 stream；逐檔核對後才以 `--receipt` 登記，中斷可從清單續作）。
2. **匯入季報** — 定期報告放 `trend-raw/reports/<系列>/` → 說「**匯入季報**」（直接更新指標頁，預測逐版加列＝vintage 追蹤）。
3. **查詢** — 「**X 最近趨勢**」「**誰在推動 X**」「**〈某公司〉最近動態**」（只讀 topics／stream，必要時回查原文；說明日期覆蓋範圍，附出處即答。**查詢不自動改庫**——說「更新／沉澱 X」才寫趨勢頁）。
4. **沉澱/回填** — 「**沉澱 X**」（編成 topics 趨勢頁）、「**把 X 回填 wiki**」（命令觸發）。

## 能提供什麼
最近動態速查、趨勢軌跡、玩家盤點/關係、跨主題 360°、餵報告/簡報素材，也當 personal-km 論述的動態佐證。

## 心法
捕獲便宜（每篇一行、不回填）；要用時才花力氣沉澱。選稿由你 clip 時完成，系統不過濾。概念只在 wiki 一份，趨勢頁只引用、不重建。

## 趨勢頁為什麼拆三個檔
每個主題是**母頁**（現況、盤點、指標＝狀態，有上界）＋**`-timeline`**（事件時間線，只增不減，按年輪替）＋**`-pending`**（待沉澱 wiki 的閘門清單）。把會無限長的時間線拆出去，母頁才不會被拖著撞分頁門檻，時間線條目也不必為了控體積而壓縮。
