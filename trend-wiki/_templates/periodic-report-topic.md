# 〈來源／主題中文全名〉— 趨勢追蹤

> **定位**：追蹤某「定期報告系列」的**週期性指標**＋**每版展望的修訂軌跡**＋**分析師看法**。回答「指標怎麼隨期變」「對未來的預測怎麼被上修／下修」。
>
> **來源型態**：低頻高價值定期報告（非新聞流），故**直接維護本頁、每期更新**，跳過一行式 stream。每版凍結原檔於 `../trend-raw/reports/<系列>/`，引用標版本如 `(來源: 〈期別〉報告V〈n〉)`。
> 單位一律：〈如 新臺幣億元〉。`(e)`＝估值、`(f)`＝預測、`實際`＝已結算。

## ★ 預測修訂追蹤（vintage）— 本框架核心
> **設計鐵則**：每出一版報告就**新增一列**記錄該版預測，**絕不覆蓋舊列**。如此可看出對同一目標期（年/季）的預測**怎麼被上修／下修**，並在實際結算後比對準度。這正是「定期報告型來源」相對一般趨勢頁的加值處。

### 全期預測逐版修訂
| 預測發布版 | 目標期 | 〈分項…〉 | **總計** | YoY | 修訂方向 |
|---|---|--:|--:|--:|---|
| V〈n〉 | 〈年T+1(e)〉 | … | … | … | — 首版 |
| V〈n〉 | 〈年T+2(f)〉 | … | … | … | — 首版 |
| _（待下一版加列）_ | 〈同目標期〉 | | | | ↑/↓/→ |

### 下一期估值 vs 實際
| 目標期 | 預測發布版 | 〈分項…〉 | **總計** | 備註 |
|---|---|--:|--:|---|
| 〈下期〉 | V〈n〉（估） | … | … | 〈環比/年增〉 |
| 〈下期〉 | _（待下一版填實際）_ | | | 屆時可算預測誤差 |

> 用法：下版報告出來時，於對應目標期**加列**與舊版並排看上下修；結算期把實際填入即得預測準度。
