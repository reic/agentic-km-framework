# wiki — 知識庫（一般食材）

> 給「人」看的使用說明。Claude 遵循的完整規範在 [WIKI.md](WIKI.md)；內容清單與查詢入口見 [index-wiki.md](index-wiki.md)。

## 這是什麼
依 **Andrej Karpathy 的 *LLM Knowledge Bases* 架構**：把 LLM 當「**編譯器**」，讀你丟進 `raw/` 的策展文件，編譯成一份結構化、互相連結的 markdown wiki。個人規模（約 100 篇文章內）**不需向量資料庫**。這裡收**客觀事實、數據、領域知識**（一般食材）；你的觀點/判斷歸 `personal-km/`（傳說食材）。
**分工**：你負責策展與判斷（哪些文件值得進來、答案對不對）；Claude 負責繁瑣簿記（摘要、交叉連結、維持一致）。

## 它能提供什麼
跨文章綜整（附出處）、概念查詢、數據基準逐年可查、投影片/圖表/報告素材；好答案回填 `derived/`，**越查越增值**。

## 日常動作
| 動作 | 你說什麼 | 結果 |
|---|---|---|
| 匯入 | 文件放 `raw/` →「匯入這份」 | 先 import_diff 比對新檔 → 摘要頁＋概念文章＋交叉連結，記 wiki-log |
| 查詢 | 「根據知識庫回答…」 | 跨多篇作答、附出處；好答案回填 derived/ |
| 健檢 | 「健檢」「數字健檢」 | 掃不一致/缺漏/孤立頁；基準稽核用 `/number-audit` |
